How coverage is measured
  • Branches: the default branch (usually main) and, if the repo has one, its dev/develop/development branch — each shown separately with the commit measured. Summary cards and sorting use the default branch.
  • Source 1 — Codecov: line coverage reported by Codecov for that commit (hits ÷ lines). Partially covered lines count as not covered.
  • Source 2 — CI artifact: if Codecov has nothing, the coverage file (Cobertura/JaCoCo XML, LCOV, Istanbul JSON, Go coverprofile) attached to the latest completed CI run on that branch.
  • Measured at: commit time of the measured commit (Codecov) or finish time of the CI run (artifact).
  • Not found means no upload or report exists — it does not mean 0%. Tests are never rerun by this dashboard.
  • Extra details: dev branch = dev/develop/development if present; main activity = commits on the default branch in the last 30 days.
