How this is measured
  • Branch. Set per repository in config/repos.json (for example development for network-adapter, main for the AI repos). The latest-release table uses each repo's highest release-* branch.
  • Code coverage. The badge is Codecov's live badge for that branch. The line count underneath comes from the last refresh: Codecov first, otherwise the coverage file saved by the latest CI run on that branch. Partially covered lines count as not covered.
  • Security. The latest completed run of the repo's security.yml on that branch. No runs on this branch means the workflow does not run there; it is not a failure.
  • Refresh data opens the refresh workflow on GitHub; click Run workflow there (needs write access to this repo). The badges are always live; line counts and run links update when the run finishes.
  • No report or an unknown badge means nothing was uploaded for that branch. It does not mean 0%. This dashboard never reruns tests.
