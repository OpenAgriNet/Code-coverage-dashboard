How coverage is measured
  • Branches. The default branch (usually main) and, if the repository has one, its dev, develop or development branch, shown only when that branch has a coverage report. The summary and sorting use the default branch.
  • Codecov first. Line coverage Codecov reports for the latest uploaded commit on that branch. Partially covered lines count as not covered.
  • CI report second. If Codecov has nothing, the coverage file (Cobertura or JaCoCo XML, LCOV, Istanbul JSON, Go cover profile) saved by the latest completed CI run on that branch.
  • Measured. Commit time of the measured commit, or finish time of the CI run.
  • No report means nothing was uploaded or saved. It does not mean 0%. This dashboard never reruns tests.
