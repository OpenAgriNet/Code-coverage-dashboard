Where this comes from
  • Packages. specfy/stack-analyser reads the manifests (package.json, go.mod, requirements.txt, pyproject.toml, compose files, workflows) on each repository's working branch. These are direct dependencies, not the full lockfile tree.
  • License and latest. From deps.dev for npm, PyPI and Go. When the listed version is a range or unknown there, the license of the latest release is shown and marked latest.
  • Vulnerabilities. From OSV.dev, Google's open vulnerability database (GitHub advisories, PyPI, Go and others). It is a public API that needs no key or login, and only package names and versions are sent. A package is checked at the version listed here; for a range such as ^5.0.0 that is the lowest version the range allows, so the real installed version may be newer and already fixed. Fixed in is the one version that fixes every fixable advisory; advisories with no released fix are counted separately.
  • Docker images and GitHub Actions are listed for completeness; their licenses are not looked up.
