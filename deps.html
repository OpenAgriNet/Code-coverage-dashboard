Where this comes from
  • Packages. specfy/stack-analyser reads the manifests (package.json, go.mod, requirements.txt, pyproject.toml, compose files, workflows) on each repository's working branch. These are direct dependencies, not the full lockfile tree.
  • License and latest. From deps.dev for npm, PyPI and Go. When the listed version is a range or unknown there, the license of the latest release is shown and marked latest.
  • Docker images and GitHub Actions are listed for completeness; their licenses are not looked up.
